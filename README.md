# Ayush Terminal — Linux-Style Interactive Portfolio

Welcome to **Ayush Terminal** — a **Linux-themed interactive portfolio website** inspired by terminal/CLI interfaces.  
Instead of a traditional scrolling portfolio, users explore your profile, projects, skills, and contacts by typing commands into a simulated Linux terminal.

💻 **Live Demo:** https://portfoliolinux.vercel.app/  
📦 **Source Code:** https://github.com/aayush-xid-su/Ayush-Terminal

---

## 🚀 What Is This Project?

**Ayush Terminal** transforms a personal portfolio into a **command-line experience**.  
Visitors interact with the site just like a Linux shell — typing commands to navigate and discover content.

This portfolio style:
- Feels **unique and memorable**
- Appeals strongly to **developers & Linux enthusiasts**
- Demonstrates **creativity, frontend skills, and system-style UX thinking**

## 📝 Available Commands

Below are the core commands supported in the terminal:

| Command | Description |
|------|------------|
| `help` | Displays all available commands |
| `about` | Shows personal introduction |
| `projects` | Lists featured projects |
| `skills` | Displays technical skills |
| `socials` | Shows social media links |
| `resume` | View or download resume |
| `contact` | Shows contact information |
| `clear` | Clears the terminal screen |
| `whoami` | Displays current user |
| `pwd` | Prints current directory |
| `echo <text>` | Prints the given text |
| `etc`| and much more commands to explore |

### 🔑 Keyboard Shortcuts
- **TAB** → Autocomplete commands  
- **↑ / ↓** → Navigate command history

## ⚙️ Local Setup & Installation

Run the project locally by following these steps:

### 1️⃣ Clone the Repository
- git clone https://github.com/aayush-xid-su/Ayush-Terminal.git
- cd Ayush-Terminal 

### 2️⃣ Install Dependencies
- npm install or
- yarn install

### 3️⃣ Start Development Server
- npm run dev or 
- yarn dev

### 4️⃣ Open in Browser
- http://localhost:3000

## 🎨 Customization Guide

You can easily personalize this terminal portfolio to match your identity:

- Edit `about` information to update your bio
- Add or remove terminal commands
- Update projects, skills, and socials
- Modify colors, fonts, and terminal theme
- Extend logic to support advanced CLI-style features

This portfolio is designed to be flexible — turn it into your own custom Linux shell.
